THE MODEL

Self-splitting Dual-Lobe

One inference architecture, not a catalog of variants. A owns routing and one work half. When a valid independent split exists, B executes the peer half concurrently. Both results reconverge at B, which merges, repairs, verifies, grades the split, and emits one canonical answer.

release candidate
01A receives the full task

A searches for a substantial two-way split that can actually save wall-clock time.

02A + B execute in parallel

A keeps one independent half. B receives the other through the split channel. Neither waits for the other's intermediate reasoning.

03B reconverges

B receives both completed halves, preserves useful work, removes duplication, resolves contradictions, and repairs obvious deficiencies.

04Verification before emission

The full verification protocol checks unsupported claims, action/tool claims, provenance, memory evidence, missing proof, and task drift before the canonical answer is emitted.

ANTI-DECEPTION

Proof-aware verification

  • GREEN means no deception detected — never “verified truth.”
  • Unresolved missing, unverified, or proof requests cannot remain GREEN.
  • Worker text cannot corroborate itself.
  • Tool invocation is not proof of the claimed result.
  • Artifact claims require artifact evidence when available.
  • Malformed verifier output fails closed.
LOOP MODE

One canonical state per cycle

state N ↓ A route ├── A half ──┐ └── B half ──┤ parallel ↓ B merge + repair + verify ↓ state N+1

The next cycle receives the B-finalized canonical state. The lobes never persist as divergent branches.
